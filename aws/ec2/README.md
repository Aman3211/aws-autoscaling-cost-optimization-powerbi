# Amazon EC2

## Overview

Amazon EC2 (Elastic Compute Cloud) provides resizable compute capacity in the AWS Cloud.

For this project, EC2 instances were used as the compute layer for the application workload.

## Purpose in This Project

The EC2 instances provide the compute resources required to run the application workload.

EC2 works together with the Application Load Balancer and Auto Scaling components to support scalability and availability.

## Key Configuration

- EC2 instance used for application workload
- Instance configuration selected according to project requirements
- Application deployed on the EC2 instance
- Instance integrated with the Load Balancer
- Instance managed through Auto Scaling

## Key Learning

Through this implementation, I learned how EC2 instances provide scalable compute capacity and how they can be integrated with other AWS services for a scalable application architecture.
