# AWS Billing & Cost Analysis

## Overview

This section documents the AWS billing and cost analysis performed as part of the AWS Auto Scaling and Cost Optimization project.

## Purpose in This Project

AWS billing information was analyzed to understand cloud resource costs and identify opportunities for cost optimization.

## Cost Analysis

The billing analysis focuses on:

- AWS resource costs
- EC2-related costs
- Usage patterns
- Cost trends
- Cost optimization opportunities

## Relationship with Power BI

The cost-related data was used as part of the project's Power BI analysis to visualize cloud infrastructure costs and support cost optimization decisions.

## Key Learning

I learned how AWS billing information can be analyzed to understand cloud spending and how cost data can support infrastructure optimization.
