# AWS Billing & Cost Analysis

This section documents the cost analysis performed as part of the **AWS Auto Scaling & Cost Optimization using Power BI** project.

The billing and cost information was reviewed to understand the cost impact of the AWS infrastructure used in the project.

---

## Objectives

- Review AWS infrastructure costs.
- Understand the cost associated with the AWS resources used in the project.
- Analyze cost information as part of the overall cost optimization objective.
- Support the cost analysis presented through the project dashboard.

## Cost Analysis

The billing information provides visibility into the cost associated with the AWS environment.

The cost analysis can be considered alongside the infrastructure monitoring and Auto Scaling configuration to understand the relationship between resource usage, scaling, and overall cloud cost.

---

## Relationship with Cost Optimization

The billing analysis forms an important part of the project's **Cost Optimization** objective.

The overall analysis combines:

- AWS infrastructure
- Auto Scaling
- CloudWatch monitoring
- Load testing
- Billing and cost information
- Power BI visualization

This provides a broader view of infrastructure performance and cloud cost.
